# djkit 教程：从一条命令到整季流水线

这套教程按**实现顺序**讲，不是按命令行参数顺序。每一篇只解决一个问题，读完能跑、能改、知道为什么这么写。

不要求你有视频剪辑经验，但要求你会敲命令行、能看懂 Python 函数。ffmpeg 不懂没关系，遇到滤镜会顺手解释。

## 两条产出路线

理解这个分叉，比记住任何命令都重要：

```
路线 A：搬运切片（快，量产后用于投流）
  素材 → scan/rename → slice → fit → report
  特点：字幕来自现成的 SRT，按文件名时间码平移

路线 B：解说片（慢，但算二创）
  素材 → hot/asr → script(三版) → 择优 → tts
       → align(配音反推时长) → assemble(按文案现排字幕) → season(汇总)
  特点：字幕不需要 ASR，文案和时长本来就在手里
```

两条路线共用底层：`compose.py` 负责单条成片，`assemble.py` 负责多段拼接，
`subtitle.py` 负责字幕，`core.py` 负责子进程与缓存。**看懂这四个文件，剩下都是编排。**

## 怎么用这套教程

1. **按顺序读**。后一篇会用到前一篇的概念（比如第 4 篇讲 filter_complex，默认你已经知道第 3 篇的字幕滤镜是怎么来的）。
2. **每篇都跑一遍命令**。教程里的命令都来自真实项目，路径换成你自己的即可。
3. **先看主代码位置，再看实现**。每篇列了对应的源文件，先扫一遍函数名再读正文，效率更高。
4. **别跳第 4 篇**。它是整个项目的地基，不懂它后面全是黑箱。

---

## 一个前提：素材授权

这套工具**不含任何下载、抓取、解析功能**。素材必须来自剧方授权包、推广平台后台或你自己拍摄的内容。

教程里出现的例子（剧集文件名、台词片段）只用于演示技术流程。工具本身不提供任何规避平台查重的手段——改 MD5、加噪点、抖动变速这类做法会被平台判定作弊，不在本教程范围内。
